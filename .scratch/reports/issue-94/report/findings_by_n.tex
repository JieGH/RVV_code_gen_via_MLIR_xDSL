\subsection*{What the n groups show}
GOPs by mean time, same runs as above.
\begin{itemize}\setlength\itemsep{1pt}
\item 1T: H is highest for n = 4 to 80; V is highest at n = 128 (6.23 against H 6.16); S is highest at n = 256 (7.72 against V 7.37 and H 6.15).
\item 1T, S against V: S is lower for every n except n = 256 (7.72 against 7.37); the largest gap is n = 4 (0.88 against 1.56).
\item 8T: V is highest at n = 4 (5.75 against H 4.16), n = 16 (9.50 against 6.18) and n = 256 (28.30 against 25.51). H is highest at n = 8, 32, 64, 80 and 128 (for example n = 32: 20.34 against V 13.74).
\item 8T, S against V: S is lower for every n, by 0.10 (n = 8) to 1.24 GOPs (n = 4).
\end{itemize}
